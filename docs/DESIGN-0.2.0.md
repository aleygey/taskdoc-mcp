# TaskDoc 0.2.0 功能与数据契约

本文件描述已实现的 0.2.0。仓库根目录的 Taskflow 文档保留为历史背景，不作为当前行为的依据。

## 核心模型

Task 是最小验收单元：稳定身份、目标、1–20 条验收、证据、执行状态、类型和归档属性。Checkpoint 是可选的独立子任务，支持判断、结果和资料；并非一次会话或一次尝试。Resume 是可覆盖的工作快照，可暂存假设、待验证修改和下一动作。

新文档 schema 为 checkpoint/v2。顶层保留旧 acceptance 字符串投影用于兼容，并以 acceptanceItems 为验收状态记录。修改时由同一服务同步这些字段。每项验收有稳定 ID：改同一条内容保持 ID，新增条目使用新 ID。旧 v1 文档在写入时转换，旧完成状态以显式复核标记保留。

任务状态独立于子任务状态，任务 blocked 需明确理由和解除条件。任务 done 需全部验收已验证或明确豁免，且没有活动/受阻子任务。任务 cancelled 结束尚未完成的子任务并保留已有资料。archive 只用于收起终态任务，不表达工作是否完成。

类型看板通过列选择类型；状态看板通过状态移动列，类型独立。设置是状态与类型映射的依据，agent 只能引用已配置值。手动看板变化视为待协调输入，不自动写入任务结论。

## 证据与修订

任务验收引用任务证据 ID，或 checkpoint/evidence 的组合 ID。不允许引用取消/被替代子任务的证据。每一条 verified 验收需要引用，waived 需要原因。任务类型进一步约束已验证项引用的证据类型。

修改目标、验收条件、证据或子任务核心会使受影响的任务验收待验证。重新打开也会重置任务验收。事实是否真实、测试是否实际运行，由人或执行者负责；结构校验不应被描述为事实认证。

任务变更记录保存最近 20 次原因与字段名称。它用于解释修订，不是完整审计日志。Checkpoint 保留已有修订号机制，以最新结构化状态为准；完整历史应使用 Vault 版本备份或版本控制。

## 接续与输出预算

有效约束和决定从非取消、非被替代的 checkpoint 中派生，含来源 ID、revision、作用范围与证据引用；约束优先返回。完成子任务不会使其决定自动失效。重评条件作为信息返回，不由插件自动推断。

接续卡过期时保留内容和过期原因。新的任务或子任务工作不应把“已改未验证”误转为最终结果。任务无 checkpoint 时也可交接。

默认 resume 返回活动核心、完成大纲和有效上下文，不读取 rich block 正文。页大小按数量和字节共同限制。活动核心过大时返回 ID 大纲并要求逐个读取。所有 MCP 工具结果限制为 64 KiB；已提交写操作的大结果返回简短成功凭据，避免诱发重复写入。

## 文件与看板一致性

TaskIndex 只缓存任务身份与路径。首次按配置目录扫描，排除 *.assets 目录；随后跟踪创建、修改、删除与改名事件。操作前始终重新读取被选中文档并检查 revision/hash。索引无法确定身份唯一性时保留真实 I/O 错误，不返回虚假的 TASK_NOT_FOUND。

Kanban 使用文本区间修改，保留无关原文、卡片附属行和设置尾部。代码/注释中的示例不作为列或卡片，Archive 区不作为普通列。新任务使用 UUID 路径和转义后的可读 alias。

查询提供文档状态与卡片状态，并隔离单卡片错误。协调先读取双向差异，应用需同时匹配预览中的两边 revision。拒绝重复链接，禁止手动勾选绕过验收。正文恢复以结构化标记为依据重建，原文件完整备份后才替换。

## 写入持久性

单插件实例串行执行变更。每个文件写入前，将 before/after 保存到插件私有日志；写入文件使用 Vault API 和内容比较。成功后在一次原子 runtime.json 替换中保存请求结果并清除日志。

异常时尝试条件回滚。重启遇到未完成日志会阻止后续写操作；诊断中的恢复会预检全部相关文件，只有当前内容与已知事务版本一致时才回滚，不覆盖后来的人工作品。多步骤对同一文件的中间版本也记录在日志中。

幂等记录使用请求 ID + 规范化参数指纹。最近 1,000 个结果可重放，较旧结果仅保留指纹并返回 IDEMPOTENCY_EXPIRED。不同参数复用 ID 返回冲突。运行日志采用临时文件、fsync 和原子替换；不承诺不同电脑、同步软件或所有共享盘上的分布式事务与断电一致性。

## 交付边界

提供桌面 Obsidian 命令与 12 个 MCP 工具。PHA 仅保留接口，不提供实际同步；不提供自动旧 win-console 导入、多写入者锁、完整修订审计或自然语言正文自动合并。每项边界均在使用说明中明确列出。
